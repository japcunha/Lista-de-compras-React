# 🛒 Lista de Compras

Um projeto simples de **Lista de Compras** desenvolvido com **React** no front-end e **Node.js** no back-end, com o objetivo de praticar a criação de aplicações full stack modernas. 
A interface é construída com **HTML**, **CSS** e **Vite**, e a API é responsável por armazenar, editar e remover os itens da lista.

---

##  Tecnologias Utilizadas:

### Front-end:
- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- HTML5
- CSS3

### Back-end:
- [Node.js](https://nodejs.org/)
- [Express](https://expressjs.com/)
- Banco de dados (opcional: pode ser MongoDB, SQLite ou outro)



##Funcionalidades:

- Adicionar itens à lista de compras 📝
- Listar todos os itens 
- Remover itens da lista 
- Comunicação entre front-end e back-end via API REST
